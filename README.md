# 絮糖

本地运行的 AI 文字冒险生成工具。输入世界观与角色设定，由你自己配置的大语言模型分步生成路线大纲、分支剧情与结局，在本机游玩。

- 免费、开源（MIT），不收集任何数据，没有服务器
- 不提供 AI 模型或 API，需自行填写兼容 OpenAI 格式的接口地址与密钥
- 设定、存档、密钥、导入的音乐都只保存在本机

## 功能

- 分步生成：资料整合 → 路线与结局大纲 → 游戏设计 → 开场 → 续写
- 路线图：可视化节点树，可直接编辑节点、前置、分岔选项去向，自动检查循环与断链
- 结局由 AI 根据数值与剧情判定，程序按条件推算并给出提醒
- 数值、角色状态、台词颜色、小游戏标记
- 背景音乐：导入你自己的音频文件，AI 按名称与标签选曲

## 使用

**安卓**：到 [Releases](../../releases) 下载 apk 安装。

**浏览器**：用任意静态服务器打开 `web/` 目录，例如：

```sh
cd web && python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

首次进入后在「设置 → API」填写接口地址、密钥和模型名。

## 自己打包 APK

需要 JDK 17 与 Android SDK（compileSdk 35）。

```sh
cd android
./build-apk.sh ../web
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

要用自己的签名：把 `keystore.properties.example` 复制为 `keystore.properties` 并填写。没有该文件时使用 Android 默认 debug 签名。

## 目录

```
web/       网页源码（全部逻辑都在这里）
android/   WebView 外壳，把 web/ 打包成 apk
```
